# 巡栈 / XunStack

服务器与应用安全检测与处置工具。后端采用 Rust，浏览器界面采用 React 与 TypeScript。

当前仓库正在接入实现源码与自动化测试，尚未发布可部署的正式版本。不得将原型效果或源码存在等同于功能已验收。

## 项目约定

- 仅维护 `README.md` 与 `AGENTS.md` 两份手写项目说明；原型直接放在 `design/` 作为视觉和交互参考。
- 代码、测试以及实际构建和运行结果是实现事实来源。
- 普通删除进入回收站；永久删除每次由后端重新验证管理员密码。
- AI 仅在原型展示；完整 Shell 和主动漏洞扫描权限不得擅自扩大。
- 目标包含 macOS 与信创 Linux；各架构须分别验证，不以交叉编译冒充实机验收。

当前未选择项目开源许可证；不自动发布软件包或修改仓库可见性。
